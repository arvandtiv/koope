# Koope Leipzig – Shopping List

An interactive shopping list for the [Koope Leipzig](https://koope.de) food cooperative, generated from the current product catalog.

## Files

| File | Description |
|------|-------------|
| `koope_einkaufszettel.html` | Interactive shopping list – open in any browser |
| `koope_einkaufsliste.md` | Plain-text product catalog with prices |

## How to use

Open `koope_einkaufszettel.html` in a browser. No server or installation needed.

**Features:**
- Check off items as you add them to your basket
- Set quantities per item (by weight or unit)
- Live cart summary with running total count
- Search/filter across all 151 products
- Progress bar showing how many items are in cart
- State persists in `localStorage` between sessions
- Dark mode support
